# cmd/agent

Агент сбора метрик. Периодически собирает системные метрики (runtime) и отправляет их на сервер по HTTP.

## Сборка

```bash
go build -o agent ./cmd/agent
```

### Со сведениями о сборке

Версия, дата и коммит подставляются линкером и печатаются в stdout при старте
(пустые значения выводятся как `N/A`):

```bash
go build -ldflags "\
  -X main.buildVersion=v1.2.3 \
  -X 'main.buildDate=$(date +%Y-%m-%d)' \
  -X main.buildCommit=$(git rev-parse --short HEAD)" \
  -o agent ./cmd/agent
```

## Запуск

```bash
./agent [флаги]
```

## Флаги и переменные окружения

| Флаг | Переменная окружения | По умолчанию | Описание |
|------|----------------------|--------------|----------|
| `-a` | `ADDRESS` | `localhost:8080` | Адрес и порт сервера метрик |
| `-r` | `REPORT_INTERVAL` | `10` | Интервал отправки метрик на сервер (сек) |
| `-p` | `POLL_INTERVAL` | `2` | Интервал сбора метрик (сек) |
| `-k` | `KEY` | `""` | Ключ для подписи данных (HMAC-SHA256) |
| `-l` | `RATE_LIMIT` | `1` | Макс. число одновременных запросов к серверу |
| `--crypto-key` | `CRYPTO_KEY` | `""` | Путь к публичному ключу для шифрования тела запросов |
| `-c` / `--config` | `CONFIG` | `""` | Путь к JSON-файлу конфигурации |

Приоритет источников: переменная окружения важнее флага, флаг важнее значения из
конфиг-файла, файл важнее значения по умолчанию (**env > flag > config-file > default**).

## Конфигурационный файл

Все опции можно задать JSON-файлом, путь — флагом `-c`/`--config` или env `CONFIG`.
Интервалы задаются строкой-длительностью (`"1s"`, `"10s"`), а не числом. Значения из
файла перекрывают дефолты, но уступают флагам и переменным окружения.

```json
{
  "address": "localhost:8080",
  "report_interval": "10s",
  "poll_interval": "2s",
  "crypto_key": "/path/to/key.pem",
  "key": "",
  "rate_limit": 1
}
```

Пример готового файла — [config.agent.json](config.agent.json):

```bash
./agent -c cmd/agent/config.agent.json
```

## Примеры

Стандартный запуск (сбор каждые 2 сек, отправка каждые 10 сек):

```bash
./agent
```

Частый сбор и отправка:

```bash
./agent -p 1 -r 5
```

Отправка на другой адрес:

```bash
./agent -a 192.168.1.10:9090
```

Через переменные окружения:

```bash
ADDRESS=my-server:8080 POLL_INTERVAL=1 REPORT_INTERVAL=5 ./agent
```

Запуск с подписью данных:

```bash
./agent -k=mysecretkey
```

## Подпись данных (HMAC-SHA256)

При указании ключа (`-k` или `KEY`) агент вычисляет HMAC-SHA256 от тела запроса (до gzip-сжатия) и передаёт хеш в HTTP-заголовке `HashSHA256`. Ключ должен совпадать с ключом сервера.

## Совместный запуск с сервером

```bash
# терминал 1 — запуск сервера
./server -k=mysecretkey

# терминал 2 — запуск агента
./agent -k=mysecretkey
```

Агент начнёт собирать runtime-метрики и отправлять их на сервер. Проверить можно в браузере: http://localhost:8080/
