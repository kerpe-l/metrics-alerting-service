# cmd/certgen

Утилита генерации самоподписанного CA и серверного TLS-сертификата для gRPC-обмена
агент→сервер. Нужна, потому что gRPC поднимается только по TLS (см.
[cmd/server](../server/README.md), [cmd/agent](../agent/README.md)).

## Что генерирует

- `ca.crt` — самоподписанный CA. Отдаётся **агенту** (`--grpc-ca`) для проверки сервера.
- `server.crt` — серверный сертификат, подписанный CA. Отдаётся **серверу** (`--grpc-cert`).
- `server.key` — приватный ключ серверного сертификата (`--grpc-key`).

Ключи — ECDSA P-256. Серверный сертификат содержит SAN, по которым агент проверяет
имя сервера при подключении.

## Запуск

```bash
go run ./cmd/certgen [флаги]
```

| Флаг | По умолчанию | Описание |
|------|--------------|----------|
| `-ca` | `ca.crt` | Путь для записи CA-сертификата |
| `-cert` | `server.crt` | Путь для записи серверного сертификата |
| `-key` | `server.key` | Путь для записи приватного ключа сервера |
| `-host` | `localhost,127.0.0.1` | SAN-имена (hostname/IP) через запятую |
| `-days` | `365` | Срок действия сертификатов в днях |

## Пример

```bash
# генерация для локального запуска
go run ./cmd/certgen -ca ca.crt -cert server.crt -key server.key

# сервер по TLS
./server -g :3200 --grpc-cert server.crt --grpc-key server.key
# агент проверяет сервер по CA
./agent -g localhost:3200 --grpc-ca ca.crt
```
