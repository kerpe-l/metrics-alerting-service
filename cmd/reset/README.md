# cmd/reset

Кодогенератор. Сканирует все пакеты модуля и для каждой структуры с маркером
`// generate:reset` создаёт метод `Reset()`, который сбрасывает поля к нулевым
значениям.

## Запуск

```sh
go run ./cmd/reset            # сканирует ./... от текущей директории
go run ./cmd/reset ./internal/...
```

Подключать директивой в корне:

```go
//go:generate go run ./cmd/reset ./...
```

## Правила сброса

| Тип поля                          | Сгенерированный код                                 |
| --------------------------------- | --------------------------------------------------- |
| `int`, `float*`, `uint*`, `complex*` | `f = 0`                                          |
| `bool`                            | `f = false`                                         |
| `string`                          | `f = ""`                                            |
| `[]T`                             | `f = f[:0]` (безопасно и для `nil`)                 |
| `map[K]V`                         | `clear(f)` (builtin, безопасен на `nil`)            |
| `*T`, у `T`/`*T` есть `Reset()`   | `if f != nil { f.Reset() }`                         |
| `*T` без `Reset()`                | `if f != nil { /* рекурсия по *f */ }`              |
| `T` (именованный) с `Reset()`     | `f.Reset()` (поле адресуемо)                        |
| `T` (именованный) без `Reset()`   | рекурсия по `Underlying()`                          |
| анонимный `struct{...}`           | рекурсия по полям с префиксом `f.x`                 |
| `interface{...}`                  | `if r, ok := f.(interface{ Reset() }); ok { r.Reset() }` |
| массивы, каналы, функции          | пропуск (поведение в задании не определено)        |

Каркас метода всегда одинаковый:

```go
// Reset сбрасывает поля T к нулевым значениям.
func (t *T) Reset() {
    if t == nil {
        return
    }
    // ... тело по таблице выше
}
```
