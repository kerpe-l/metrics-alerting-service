# crypto

Гибридное шифрование трафика агент→сервер. Godoc: см. [crypto.go](crypto.go).

## Зачем гибрид

RSA шифрует данные не больше размера ключа за вычетом паддинга (~190 байт для
RSA-2048 с OAEP). Батчи метрик больше, поэтому:

- тело шифруется симметрично **AES-256-GCM** случайным сеансовым ключом;
- сам сеансовый ключ шифруется **RSA-OAEP** публичным ключом сервера.

Формат зашифрованного тела:

```
uint16(len(encKey)) || encKey(RSA-OAEP) || nonce||ciphertext(AES-GCM)
```

## Порядок на сервере

`Middleware` должен стоять **снаружи** gzip-middleware: `decrypt → gunzip → verify hash`.
Расшифровка применяется только к запросам с заголовком `X-Encrypted`, поэтому
незашифрованные запросы (`/ping`) проходят насквозь. `nil` приватный ключ —
прозрачный pass-through.

## Ключи

Поддерживаются PEM-форматы: публичный — PKIX или PKCS1, приватный — PKCS8 или PKCS1.
Сгенерировать пару можно утилитой [`cmd/keygen`](../../cmd/keygen) или `openssl`.

## Зависимости

Только стандартная библиотека (`crypto/rsa`, `crypto/aes`, `crypto/cipher`).
