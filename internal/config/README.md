# internal/config

В этом пакете хранятся конфигурации приложения.

Источники конфигурации: значения по умолчанию, JSON-файл, флаги командной строки,
переменные окружения. Приоритет — **env > flag > config-file > default**.

Описание конкретных параметров сервера и агента — в README соответствующих бинарей:
[cmd/server](../../cmd/server/README.md), [cmd/agent](../../cmd/agent/README.md).

## Конфигурационный файл

Путь к JSON-файлу задаётся флагом `-c`/`-config` или env `CONFIG` (env важнее флага).
Файл покрывает все опции; интервалы записываются строкой-длительностью (`"5s"`), а в
структуру `*Config` переводятся в целые секунды.

Ключевое решение по приоритету: после `flag.Parse()` нельзя отличить явно заданный флаг
от взятого по умолчанию, поэтому через `FlagSet.Visit` собирается множество явно
заданных флагов, и значение из файла применяется к полю только если его флаг не задан.
Поля JSON-структур — указатели, чтобы отличать отсутствующий ключ от пустого значения.
