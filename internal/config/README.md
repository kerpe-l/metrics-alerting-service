# internal/config

В этом пакете хранятся конфигурации приложения.

Загрузку конфигурации можно реализовать из различных источников, например: файлов, переменных окружения, баз данных и других.

Описание конкретных параметров сервера и агента — в README соответствующих бинарей: [cmd/server](../../cmd/server/README.md), [cmd/agent](../../cmd/agent/README.md). Приоритет источников: env > flag > default.
